A dependency-free, byte-exact GFM renderer modelled on marked 18.1.3's default
output, with a block scanner and inline scanner tuned for long documents.

## Run it

```sh
node main.ts
```

Reads `$MAKEFUN_INPUT_DIR/cases.json` (default `/input`) and writes
`$MAKEFUN_OUTPUT_DIR/html.json` (default `/output`).
